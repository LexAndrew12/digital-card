# Zoltai Sándor – digitális névjegy

## GitHub Pages közzététel

1. Hozz létre GitHubon egy új, nyilvános repositoryt, például: `digital-card`.
2. Töltsd fel a mappa összes fájlját a repository gyökerébe.
3. Nyisd meg: **Settings → Pages**.
4. A **Build and deployment** résznél válaszd:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Mentsd el.
6. Néhány perc múlva az oldal címe várhatóan:
   `https://FELHASZNALONEV.github.io/digital-card/`

Ezt az URL-t kell majd az NFC tagre írni URL rekordként.

## Szerkesztés

- Portré: `sandor.jpg`
- Szövegek és linkek: `index.html`
- Megjelenés: `style.css`
- Kontaktadatok: `zoltai-sandor.vcf`
